Renders one of the [Tabler Icons](https://tabler.io/icons) as `<i class="ti ti-{name}">`. It needs the
`@tabler/icons-webfont` stylesheet, see [Installation](/getting-started/installation/).

<Example name="icon/all-in-one" />

`name` is the icon name without the `ti-` prefix, as listed on [tabler.io/icons](https://tabler.io/icons). The webfont
draws the outline icons only: names like `star-filled` render nothing.

`variant` sets the color (`text-{variant}`):

## Attributes

The icon inherits the font size and color of its parent. Other attributes go to the `<i>`: a spacing class next to a
label, a font-size class, or `role="img"` and an `aria-label` when the icon carries meaning on its own:

<Example name="icon/attributes" />

## Props

| Prop        | Type    | Default    | Description                                                              |
| ----------- | ------- | ---------- | ------------------------------------------------------------------------ |
| `name`      | string  | (required) | Icon name, without the `ti-` prefix                                      |
| `variant`   | string? | `null`     | `primary` `secondary` `success` `danger` `warning` `info` `dark` `light` |
| `animation` | string? | `null`     | `pulse` `tada` `rotate`                                                  |
